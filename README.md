## 🔍 About the Project

**Toko Online** is a mobile e-commerce application built around the principle:

> *"Simplicity is the Ultimate Sophistication."*

The primary focus of this project is to deliver a seamless shopping experience and an efficient product management system — free from unnecessary feature complexity.

This application serves as a competency demonstration in integrating a **Flutter frontend** with a **REST API**, validated through backend testing in **Postman**. It was developed as the final project requirement for the Mobile Apps module at **SMK Telkom Malang**.

---

## 🌟 Why Simplicity Wins

Unlike typical e-commerce applications cluttered with ads and complex navigation, this project is built on four core principles:

| Principle | Description |
|-----------|-------------|
| ⚡ **Performance Efficiency** | No heavy animations — the app runs smoothly even on low-spec devices |
| 🧠 **Zero Learning Curve** | An intuitive design that allows users to complete a transaction within seconds |
| 🔒 **Data Stability** | Solid API integration ensures consistent data integrity between the app and server |
| 🎨 **Clean UI** | A modern color scheme and clean layout designed for comfortable, eye-friendly usage |

## 🚀 Getting Started

### Prerequisites

- [Flutter SDK](https://flutter.dev/docs/get-started/install) installed and configured
- A running backend / API server (tested via Postman)
- A connected device or emulator (Android / iOS)
- Git

### Installation

1. **Clone the repository:**

   ```bash
   git clone https://github.com/WagyuuA5/project_modul_api1_toko.git
   ```

2. **Navigate to the project directory:**

   ```bash
   cd flutter_application_1
   ```

3. **Install dependencies:**

   ```bash
   flutter pub get
   ```

4. **Run the application:**

   ```bash
   flutter run
   ```

> For a release build: `flutter build apk` (Android) or `flutter build ios` (iOS)
